LEGACY FORGE — THE CROWN JEWEL (v1.3.1 – v1.5.1)
--------------------------------------------------------------------------------
Modern launchers abandoned old Forge. We resurrected it.

Most launchers throw up their hands when they see Minecraft 1.4.7 + Forge.
Not KrypLauncher. We rebuilt the entire pipeline to make ancient modded
Minecraft install and launch flawlessly.

  * Universal Installer Magic
    Old Forge versions (1.5.1 and below) don't ship a normal installer.
    Instead of chasing a broken installer.jar, KrypLauncher automatically
    detects these versions and uses the correct "Universal" build directly —
    the same file Forge intended. No more 404 errors. No more dead ends.

  * Smart Detection (isOldUniversalMc)
    The launcher inspects every version before installing and instantly
    recognises 1.5.1 and older. It then switches to the legacy pipeline
    automatically — you just click Install.

  * Automatic FML Libraries
    The four ancient Forge libraries every old version craves are fetched and
    staged automatically: argo, guava, asm-all, and bcprov.
    No manual downloads, no hunting forums for jars from 2013.

  * Battle-Tested
    Verified on real installs: Minecraft 1.4.4 and 1.4.7 — install, removal,
    and launching into the game menu all pass. Old versions pair up with the
    correct old Java automatically, so nothing crashes at startup.

  HOW IT WORKS: Press Install → KrypLauncher detects the legacy version →
  downloads the Universal Forge → stages the 4 FML libraries → builds the
  profile → launches with the right Java. Done. You're in 2013.
